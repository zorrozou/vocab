# 核心算法调研与 v2.0 升级方案（2026-10-26）

## 调研结论

### 1. Duolingo：HLR 与 Birdbrain

- HLR（Settles & Meeder, ACL 2016）用 `p=2^(-δ/h)` 描述遗忘，半衰期由学习者与单词特征共同决定，并使用 1300 万学习记录训练。它证明"每词的记忆曲线不同"比统一阶梯更重要。
- Birdbrain 预测每道具体练习的正确率，再选择难度适中的练习，而不是只给用户一个固定总分。
- 来源：
  - https://aclanthology.org/P16-1174/
  - https://github.com/duolingo/halflife-regression
  - https://indiaai.gov.in/article/duolingo-s-klinton-bicknell-on-ai-creating-high-quality-learning-experiences

### 2. Lingvist：Knowledge Mapping Engine

KME 用最多约 50 个不同难度的翻译题，结合相似用户的历史数据，预测另外 2000 多个词哪些会、哪些不会，再关闭已会词、开启未知词。官方称预测准确率最高约 90%。重点不是精确总词汇量，而是**词级知识预测**。

来源：https://lingvist.com/blog/spaced-repetition-in-learning/

### 3. BKT：Bayesian Knowledge Tracing

BKT 把每个知识点建模为"会/不会"的隐状态，通过答题序列估计掌握概率。可带猜测、滑倒和遗忘参数。我们的 `a/b` 词级证据是它的轻量实现，后续可用真实数据估计参数，而不是拍脑袋设权重。

来源：
- https://github.com/CAHLR/pyBKT
- https://www.mdpi.com/2624-8611/5/3/50

### 4. FSRS：继续负责复习间隔

FSRS 用难度、稳定度、可提取度决定复习时间，支持根据个人复习历史优化参数。它的职责是"什么时候复习"，不是"测出词汇量"。当前应用保留已验证的 FSRS-6 全链路，不把定级和调度混为一个算法。

来源：
- https://github.com/open-spaced-repetition/fsrs4anki
- https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md

### 5. Duolingo English Test：CAT/IRT 的边界

DET 使用 IRT 和 CAT，按当前能力估计选题并估计后验能力。它说明 CAT 本身不是问题，问题是**把很小的题库和再认题直接映射为精确词汇量**，而没有词级模型和校准数据。

来源：https://duolingo-papers.s3.us-east-1.amazonaws.com/other/technical_manual/DET_technical_manual_2026_07.pdf

## v2.0 第一阶段实现

### 词级知识概率

- 每词保存 `a/b` 证据：答对增加 a，答错/不认识增加 b
- 每个词汇量档位保存先验证据，避免只用一个全局分数
- 已学卡片优先使用 FSRS 的可提取度 `R(t)`，未学词使用档位先验
- 定级答题同时更新词级证据和档位证据；日常 learn/review 更新词级证据

### 预计认识词数

`预计认识词数 = Σ P(认识)`

- 有词级证据的词用自己的概率
- 其他词使用所在档位的概率
- 已学卡片用 FSRS 的 R(t) 替代档位先验

这样避免把一次测试的点估值当成真实词汇量，后续每天只会随证据缓慢变化，而不是一次重测就大幅跳动。

### 发词位置

从低到高找第一个后验通过率低于 75% 的档位，在该档位内按通过率决定发词位置。档位只是粗边界，不再用单次测试的总分直接跳级。

## 与旧方案的关系

- 固定 30 题、前 12 题逐层覆盖、后 18 题集中边界：保留，避免前段跳级
- "不认识"按钮：保留，减少把猜对当掌握
- FSRS 调度：不变
- 每日主动探测、置信度扩散、级别滞回：保留，但展示改为预计认识词数

## 后续阶段

1. 用真实作答数据估计每词猜测/滑倒参数，而不是固定 0.25
2. 用 HLR 的 `p=2^(-δ/h)` 或 FSRS 的 R(t) 统一不同时间点的知识概率
3. 用独立留出测验计算真实误差，而不是只报告模型内部标准差
4. 根据用户真实复习结果优化 FSRS 参数和例句复现频率
