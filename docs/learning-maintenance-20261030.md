# 学习维护与内容质量：2026-10-30 验收记录

本轮交付异常卡恢复、长期存档维护、实际学习效果统计、今日任务离线包和词库质量修复。生产发布于 2026-10-30，继续使用同一 FSRS 版本、目标保持率和每日名额规则。

## 用户可见功能

- **设置 → 离线与数据维护**：查看异常卡原因，先保存本机完整快照，再从可验证的历史起点、原评分时间和原参数版本重算。评分 ID 与掌握证据保持不变。缺失起点、未知参数或相互矛盾的事件不会被“重置”掩盖；原卡与备份保留，其他卡仍可学习和同步。
- **设置 / 统计 → 实际学习效果与存档健康**：显示服务器已同步的最近 28 天延迟回忆、遗忘与困难次数、当前积压、待处理评分、状态体积、整理预计收益和有效训练观测。学习展示、即时验收、提示后作答与待同步评分不算有效保持率观测；日明细明确标为可追溯记录，不能冒充完整历史。
- **下载今日任务离线包**：先在线领取共享名额，再下载词义、双向题目、三档静态例句和对应音频。每批最多 100 个已领取词，逐词确认完整性，失败可重试。浏览器离线刷新仍可打开应用；iOS 内容按服务器与词库版本持久保存。跨日不沿用昨天的名额，变更词库或嗓音需要重新下载。在线生成的个人例句不在此离线包内。
- **自动备份维护**：每日已验证备份继续按现有 30 份策略轮换；增加独立的压缩月度恢复点，相同的只读词库快照使用硬链接去重。写入、校验失败时保留旧备份。月度档案保留，不随日备份轮换删除。

活动评分历史仍使用现有的受保护整理流程：先同步其他设备，再备份、检查版本和建立新基线。不会为了自动缩减体积而使其他设备的离线评分失效，也不改发出的每日名额。备份自动化与活动历史整理是不同操作。

- **内容纠错**：Web 与 iOS 增加词义及例句纠错，反馈按请求与内容去重、需要登录或服务器游客凭证，进入私有编辑复核队列。提供去除账号标识的只读导出工具；不会凭单次报告直接改写公共词库。
- **整库离线**：约 19.6 MiB、86 个分包，含全部有效词的词义、双向题目、三档例句及候选句。逐包 SHA-256 校验，暂停续传，损坏分包重下，全部写入后才启用；与 800 条日常缓存分开，可独立删除且不清除进度。Web 等待支持整库读取的 Service Worker 接管后才开始下载；新包完成后同步内容版本。修复缓存写入/打开失败遮住正常线上响应的问题。
- **离线练习与语音**：没有联网生成结果时，根据近期遗忘选用本机例句；已有本机英语语音可作为音频未缓存时的回退。「本机生成薄弱词例句」每次最多 3 词，仅使用已经就绪的中英双语本地模型，不自动下载模型、不上传输入。生成内容经结构检查及六项评审，只作阅读、不写入公共词库、不产生评分或掌握证据。模型不可用时明确显示保存的例句。云端生成及待处理任务继续保留。

本机模型取决于系统、地区、语言和模型可用性。iOS 使用 iOS 26+ Foundation Models 的 `SystemLanguageModel`；Web 检测浏览器 `LanguageModel` 的中英双语能力，只有 `available` 才创建会话。当前测试环境没有可用的双语本机模型，因此真实模型生成质量尚未完成设备验收；已验证不可用回退、质量拒绝、资源释放和不下载模型的行为。不能据此声称所有设备都能离线生成新句。
