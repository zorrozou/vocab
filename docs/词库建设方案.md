- 版本：v1.0（定稿）
- 日期：2026-08-06
- 关联文档：`PRD-艾宾浩斯背单词App.md` §3.7、§4
- 状态：原型管线已验证（`build_lexicon.py` → `data/lexicon.sqlite`）

---

## 1. 为什么词库先于调度器

调度器是纯逻辑，合成数据随时可测；词库是内容重资产——**学习顺序、例句召回、TTS、UI、学前测词全部以它为前置**，且例句编写/筛选是整个项目工作量最大的单项。因此里程碑调整为：

- **M0'（词库构建管线 + L1 切片）先行**；M0（调度器对拍）可与词库并行，不阻塞；
- M1 界面开发以 **L1~L3 词库就绪**为开工条件。

## 2. 数据源选型（定稿）

| 用途 | 数据源 | 说明 |
|---|---|---|
| **主词典** | **ECDICT**（github.com/skywind3000/ECDICT） | 字段完全匹配我们的架构：`word / phonetic / definition / translation / pos / collins / oxford / tag / bnc / frq / exchange`；`tag` 自带 zk(中考)/gk(高考)/cet4/cet6/ky(考研)/ielts/toefl 考纲标签；`frq` 为当代语料库词频、`bnc` 为英国国家语料库词频；`exchange` 提供词形变化与 Lemma |
| 词频排序 | ECDICT `frq` 为主、`bnc` 为辅 | frq 偏现代语料（杂志/科技），bnc 偏经典文本；L1~L3 用 frq，L6 取 frq 8000~12000 区间带 |
| 例句 | Tatoeba（CC-BY 开源句库）按词表过滤 + **前 500 词预编受控句** | 冷启动句必须手写受控句；其余用倒排索引从 Tatoeba 筛 |
| 原型验证 | Google ngram 10k 词频表 | 已用于本次管线验证（`data/google-10000.txt`） |
| 音频 | v1 用系统 TTS；真人发音留作 v2 内容包 | — |

**许可注意**：ECDICT 整理自公开词典资料，开源可获取，但**商用发布前需逐项确认其数据构成许可**；COCA 官方词表为付费授权，用 ECDICT `frq` 替代即可规避。

## 3. 数据 Schema

沿用 PRD §4（`LexiconEntry` / `Sentence`），补充两个字段：

- `LexiconEntry.source`：数据来源标记（ecdict / 手工增补）
- `LexiconEntry.lemma`：词干（来自 ECDICT `exchange` 的 `0:` 项），用于词形归并

生产环境统一编译为 **SQLite 只读库**随 App 打包；词包更新走整库替换。

## 4. 构建管线（六步）

```
ingest        ECDICT stardict.csv → 过滤有效词条（非词组碎片、有释义）
normalize     小写化；用 exchange/Lemma 把词形变体归并到主词条（drinks→drink）
rank & level  按 frq 排序切带：L1(1-1000) L2(1001-3000) L3(cet4增量)
              L4(cet6增量) L5(ielts/toefl 增量) L6(frq 8000-12000)
tag           映射 ECDICT tag → examTags（一词多标签）
sentences     先筛后造（实义词口径实测定配）：① Tatoeba 严格过滤 → 实义词共现筛选
              （召回词限名/动/形），实测覆盖 L1 93% / L2 75% / L3 36%；
              ② 缺口 LLM 生成补齐；③ 冷启动前 300 词人工预编。义项归属启发式 + 抽检。
              句长策略：跟读主句 ≤12，展示/语境句 ≤16~18。
              定位：静态句负责"预期遗忘点近似加固"；个人失败词的针对性巩固
              由运行时动态选句层与夜间个性化层承担
validate      输出校验报告（见 §5），不合格不打包
```

原型实现：`build_lexicon.py`（已验证 schema、分级切带、倒排标注、召回查询全链路）。

## 5. 校验标准（打包门禁）

1. **例句覆盖**：L1~L3 每词 ≥ 2 条例句，L1 必须 100% 覆盖
2. **可学性回放**：按词频序模拟学习过程，每个词在其学习时点必须存在 ≥1 条"已知词覆盖率 ≥95%"的例句（冷启动段豁免，用预编句兜底）
3. **lemma 归并率**：例句 token 归并失败率 < 1%，剩余按专名/数字白名单处理
4. **召回性能**：例句选择查询 < 50ms（万级句库 + 倒排索引）
5. **重复度**：任意两词共用例句比例低于阈值，避免学习卡片雷同

## 6. 冷启动例句编写规范（前 500 词）

- 句长 3~8 词；用词严格限于"该词学习时点之前"的词 + 数字/专名
- 每词 2~3 句：1 句超高频搭配（如 have a good time），1 句语境化短句
- 中文翻译一句一行，口语化
- L5/L6 学术词特例：配**短句、生活化语境**，难度集中在目标词本身

## 7. 原型验证结果（2026-08-06）

- `data/lexicon.sqlite`：L1 1000 词 + L2 2000 词（Google ngram 演示切片）
- 12 条预编例句完成 wordIds 标注与入库
- 召回查询演示通过：硬过滤（已学集合 + 句长）→ 遗忘风险打分 → 加权随机选中
- **抓到一个真实问题**：`drinks`、`mountains` 等词形变体不在词表切片中 → 证实 §4 normalize 步（lemma 归并）是生产必需，ECDICT `exchange` 字段正好解决
