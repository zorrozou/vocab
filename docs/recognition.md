# 词义识别估计 v1（2026-11-05）

## 产品边界

估计对象为当前词库 10,987 个词条的词义识别，允许听单词发音辅助。不是英语全部词汇、词族数、稳定掌握数，也不评估听力篇章理解或说写能力。结果只展示范围；没有足够可追溯记录时显示“待校准”。已掌握状态、FSRS、学习日志、每日 10 个新词／100 个不同词规则不变。

30 题初测优先补足六个词频档的覆盖；正常新测每档 5 题，档内均匀随机、无放回抽样。每日原有最多 3 道探测改为同方向的新题，在样本少的档位补充证据。在新词名额之后为校准预留位置，避免积压复习长期挤掉校准；题目加载失败时将位置还给复习。它们遵守原有共享名额；不强迫用户额外完成一轮测试。网络错误和缺少版本标识的旧题不能写入新证据。

新学习起点来自同一分档观测：以带猜测项的均匀 q 先验后验均值判断档位是否达到 .75；在第一个未达到的档位内保守起步。正确率不高于随机猜测、或缺少证据时从该档起点开始。起点是探索建议，不是“此前所有词已掌握”的声明。原已完成用户的游标保留；每天不再按旧后验自动大幅跳词。

## 计算与限制

每档真实识别比例 q ∈ [0,1]，观察正确率模型为 p=.25+.75q。维护各档独立二项似然；不再用原始正确率乘档位大小，也不以词频排名直接等同实测题目难度。点估计仍可能受有限样本、边界截断影响，因此只作为内部诊断，不能直接显示给用户。

范围计算：投影六参数联合似然区域，允许对数似然比下降 6.295793621871989（理论 chi-square_6 的 .95 分位除以 2），用拉格朗日乘子搜索总识别词数的上下界。缺少样本的档位贡献 [0,档位大小]；对训练／待学词的非随机排除，再按完整排除词数向两侧保守扩展。范围向外取整到百词，并限制在词库内。不是宣称经过真人验证的“95% 准确率”；猜测、选项排除、遗忘、测量范围漂移、重复查看答案等可能违背模型假设。

最初尝试的一参数似然区间在纯猜测模拟上覆盖不足，已拒绝使用。保留多档联合不确定性后，初测范围较宽是预期结果，不能为了视觉好看而缩窄。更多独立新题才能增加证据。

## 证据与同步

`recognitionEvidence` 是与旧 `posteriorHistory`、`bandEvidence`、FSRS 分离的不可变事件表，记录版本、词形、位置、实际答案、时间、来源和题目内容指纹。旧贝叶斯历史继续兼容同步，但不再决定展示范围、抽题或自动跳词。每个位置只采用最早一次独立观测；跨端重复事件保留，但不会增加样本数。

旧记录只复用可证明属于“前 12 题、依序每档两题”的事件，后续集中在边界的 18 题不能代表整个档位。无法证明的聚合统计不用作新模型的样本。服务器整理历史前把可复用旧样本固化，避免被最近日志或后验整理丢掉。共享任务保留 `probe_sampler`，只有已标记的分档抽样进入新证据；旧任务不得被新请求重新贴标签。旧客户端缺少新字段时，服务端合并保留已有证据；明确重新定级才切换整轮证据。备份／恢复和恢复版本机制沿用现有流程。

题目采用 `assessment=true` 的固定版本：同词、同词库修订返回相同选项与内容指纹，优先同词性、相近长度、无已知释义重叠的干扰项。普通练习题保持原行为。所有词仍属于当前固定词库；未来变更词库排序时必须同时升级证据映射规则，不能混用不同位置的词条。

独立校验改为整库六档各 4 题，排除当前已测／已学／待学位置，与正式估计使用同一计算方式，报告区间是否重叠。仅保存报告，不写入正式识别证据、学习调度或游标。旧版“独立校验”只覆盖到约 4,500 词，不能作为高水平用户的全库基准。

新版校验使用 `POST /api/v1/placement/assessment`，把排除位置放在有长度限制的 JSON 正文中，避免长期账号的排除列表超过反向代理的网址长度限制。旧的 GET 接口保留兼容。

## 验证

- `node tests/web_recognition_check.cjs`：稀疏证据、猜测校正、练习不抬高估计、30 题覆盖、重启、重复去重、旧样本资格；五个已知词数场景各 300 次模拟。
- `swiftc -O ios/VocabApp/Models.swift ios/VocabApp/StudyEngine.swift tests/ios_placement_selection.swift -o /tmp/recognition-check && /tmp/recognition-check`：Swift 与 Web 的共享数值夹具、起点、重启和 30 题覆盖。
- `../audit-venv/bin/python server/test_recognition_evidence.py`：双端并集、旧客户端、复原代次、坏事件、历史整理和旧抽测保留。
- `tests/web_recognition_e2e.cjs`：真实隔离 API 上的正误作答、30 题分档、刷新续测、24 题独立校验、旧学习状态不被改写和不自动跳词。
- `tests/recognition_http_check.py`：5,493 个已学／已测位置排除、整库分档覆盖、非法输入和题库耗尽。
- `tests/run_ios_ui_regression.sh SIMULATOR_ID replace` 与 `recognition`：小屏 iPhone 续测、完成页、同步与独立校验。

初轮确定性模拟（均匀四选一猜测，已知词必答对，正常每档 5 题）：真实词数 0／3,000／6,000／9,000／10,987 的范围覆盖比例分别为 98.3%／100%／100%／100%／100%。这是模拟诊断，不能推导真人测量准确率。真实有效性需继续通过未见题的预测表现、重复测量和选项质量数据检验，不宣称算法已最优。

## 发布与回退

先备份服务器学习数据库和旧代码，发布可保留新字段的兼容服务端，再发布网页和 App。覆盖安装前后核对本机学习／恢复文件。回退界面时保留服务端的新证据合并兼容层，不回写旧数据库快照覆盖上线后的学习。当前学习状态不因估计变化而清空。
