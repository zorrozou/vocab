# 英语教练改造与回退

## 学习目标和发布顺序

用户在真实生活或工作中听懂、读懂一则消息，并作出合适的回应。教练根据首次作答、所选项、原文提示和跨日表现备课。用户无需提供材料。以听读为主，每 10 分钟约 8 分钟理解、最多 2 分钟可选表达，作为试点目标。

1. **本次试点**。两端共用一个账号和服务端课程记录。让用户在生活或工作主题中开始，每天一课。首次理解失误或听后需要原文时给带线索的练习，再换情境验证。汇总独立完成数，按最近表现选择后续重点。旧课经过七天后安排新情境复查。客观题有固定依据，用户可以对照参考说法练习一句简短回应，也可以要求混元结合本题和所选答案解释。课程表不写入 FSRS，不把背景词加入每日名单。首版为 3 个教学重点、18 则经编辑的材料。
2. **按效果扩充课程**。从第一课建立基线，比较相同用时下 7 天后的陌生任务独立完成情况，30 天后回看。独立记录纯听、重复播放、看原文和独立阅读，避免把看懂字幕当作听懂。累计样本后扩展课程和内容生成，人工抽检歧义题及错误反馈。根据实际练习用时重新分配词汇和课程占比。
3. **轻表达**。在听读有效且用户愿意表达的场景加入短写作或一句话口头回应。先用经教师复核的答案测试误判率，再让评估进入教学档案。没有声学依据的转写不能给发音打分。

## 每日时间和学习档案

经典界面和教练课共享同一账号日预算。30 分钟暂停，用户可以选择延长，当天总量 40 分钟封顶。首页、设置、完成小结不占课堂时间。到点时保留已提交结果，未提交的答案不评分。游客按本设备的游客凭证计时。已发布的旧客户端没有计时能力。同账号的学习日按首次使用计时功能时的时区偏移划分，防止两端因时区不同重复领用时间。

服务端在 SQLite 事务中发放短时段，断网或计时未确认时暂停。需要离线背词时，联网进入练习后可预留当前连续时段最多 10 分钟，不超过当天剩余量。无法联网通知服务端暂停时，该时段最晚按到期收回。课程作答需联网。切换设备时先暂停，异常离开后服务端自动回收。课内时间和课程证据存放在 personal.db 的独立 coach_* 表，包含在既有数据库备份中，旧版学习存档不会覆盖这些表。

## 两层回退

- **用户切换**。首页点「切回经典界面」，需要教练时再点「开启听读教练」。操作不删除课程、背词进度或今天的计时。iOS 和 Web 可各自保留界面偏好。
- **运维关闭试点**。在服务数据目录创建 `coach.disabled` 即停止发课和提交课程结果。用户回首页后隐藏教练入口，经典练习和共享时间继续工作。移走该标记即可重新开放。
- **代码发布故障**。完整回退基线为 Git 标签 `baseline-before-coach-20261104`（`8618ca3`）。切回发布前的前后端文件和兼容客户端，不卸载 App，不清本地存档，不用旧数据库覆盖上线后新增的学习。服务器发布备份中保存软件回退脚本及停写时制作的数据库备份。全量恢复旧二进制会恢复旧版自身的能力，包括旧版没有的计时功能。
