# 英语教练改造与回退

## 目标与使用方式

用户只选择想做到的事情，教练负责准备材料。日常听说、职场沟通、阅读理解三个目标随账号保存。首页的今日安排由剩余时间、到期词数及近期课堂表现决定。默认建议 8 分钟听读、20 分钟词汇、2 分钟可选回应。需要多复习时缩短听读环节，近期需要帮助较多时给听读留更多时间。当天剩余不足 6 分钟则不再开一节新课程。

- **备课**。进入新课时，向已有混元服务提供教学重点、待验证原因、近似词汇位置和最多三个近期薄弱词。首轮生成三个新情境，再单独审校语义、选项、核验题和回复。与本地教材或历史材料高度重复、结构不完整或有一则未通过，就使用教研课程。返回首页可继续其他任务，或直接选择教研材料。材料与正误依据在开课时冻结，两端读同一份。旧版未完成课程有独立的接续入口。
- **上课**。接收消息，做出行动，再换情境独立验证。首次需要帮助时加一道具体核验题。每个错误选项都有对应的教学线索。听读和重听分别记录，展开原文后的听力作答不计首听。可以撤销最近一次选择，已看过反馈的重选保留为辅助练习。
- **轻回应**。可跳过，也可用不超过 180 个字符的英文表达。支持时可以先转写，再检查文字。iOS 使用本机识别，浏览器语音可能由浏览器供应商处理。主动发送时才将文字交给模型；只保留形成性反馈和参考说法，支持依建议再改写一次。判断不确定时回到参考说法。未以此改变 FSRS、判定发音或证明自由口语能力。
- **教学档案**。按近期多次作答决定补弱或推进。久别重返先复查。第 7 天或第 30 天后的复查窗口优先安排陌生材料。留出题不用于平时训练，使用过的材料不当作“陌生题”。周报列出样本数、学生实际选择过的行动和证据不足项。模型切换不会清空档案。
- **自愿的学习方式对照**。在「我的目标」开启，之后的同技能、同目标训练成对分配固定流程和错项分支；试验使用教研教材。按学习者、技能、目标、词汇位置区间、延迟和两分钟训练时长区间匹配复查成绩。可在同一页退出。只报告实际观察，不将空样本、模拟数据或前后差异解释成真实教学效果。该对照研究的是两种教学流程，不能独立证明整个产品优于所有背词工具。

## 验收边界

自动回归覆盖目标与档案隔离、旧课续学、新教材的生成/拒绝/冻结、两种诊断分支、撤销后旧提交失效、回应反馈、按天接续与计时。使用冻结时钟验证 7/30 日调度只说明程序能正确发放验证题。学习收益需要真实用户在相应日期返回。模型对开放回应的建议属于低风险练习；正式评分还需要教师标注的一致性评估。

## 每日时间和学习档案

经典界面和教练课共享同一账号日预算。30 分钟暂停，用户可以选择延长，当天总量 40 分钟封顶。首页、设置、完成小结不占课堂时间。到点时保留已提交结果，未提交的答案不评分。游客按本设备的游客凭证计时。已发布的旧客户端没有计时能力。同账号的学习日按首次使用计时功能时的时区偏移划分，防止两端因时区不同重复领用时间。

服务端在 SQLite 事务中发放短时段，断网或计时未确认时暂停。需要离线背词时，联网进入练习后可预留当前连续时段最多 10 分钟，不超过当天剩余量。无法联网通知服务端暂停时，该时段最晚按到期收回。课程作答需联网。备课页面等待模型不占动手练习时间。切换设备时先暂停，异常离开后服务端自动回收。课内时间、教学目标、冻结的课程材料和作答证据存放在 personal.db 的独立 coach_* 表，包含在既有数据库备份中，旧版学习存档不会覆盖这些表。

## 两层回退

- **用户切换**。首页点「切回经典界面」，需要教练时再点「开启听读教练」。操作不删除课程、背词进度或今天的计时。iOS 和 Web 可各自保留界面偏好。
- **运维关闭试点**。在服务数据目录创建 `coach.disabled` 即停止发课和提交课程结果。用户回首页后隐藏教练入口，经典练习和共享时间继续工作。移走该标记即可重新开放。
- **代码发布故障**。完整回退基线为 Git 标签 `baseline-before-coach-20261104`（`8618ca3`）。切回发布前的前后端文件和兼容客户端，不卸载 App，不清本地存档，不用旧数据库覆盖上线后新增的学习。服务器发布备份中保存软件回退脚本及停写时制作的数据库备份。全量恢复旧二进制会恢复旧版自身的能力，包括旧版没有的计时功能。
