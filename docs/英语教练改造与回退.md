# 英语教练改造与回退

## 目标与使用方式

用户只选择想做到的事情，教练负责准备材料。日常听说、职场沟通、阅读理解三个目标随账号保存。首页的今日安排由约 30 分钟的参考时长、到期词数及近期课堂表现决定。默认建议 8 分钟听读、20 分钟词汇、2 分钟可选回应。需要多复习时缩短听读环节，近期需要帮助较多时给听读留更多时间。实际用时不会阻挡开课或继续练习。

- **备课**。前一天结束练习后由后台向已有混元服务提供教学重点、待验证原因、近似词汇位置和最多三个近期薄弱词。首轮生成三个新情境，再单独审校语义、选项、核验题和回复。与本地教材或历史材料高度重复、结构不完整或有一则未通过，就使用教研课程。打开课程直接取已备材料，未备好时可以立即使用教研材料。材料与正误依据在开课时冻结，两端读同一份。旧版未完成课程有独立的接续入口。
- **上课**。接收消息，做出行动，再换情境独立验证。首次需要帮助时加一道具体核验题。每个错误选项都有对应的教学线索。听读和重听分别记录，展开原文后的听力作答不计首听。可以撤销最近一次选择，已看过反馈的重选保留为辅助练习。
- **轻回应**。可跳过，也可用不超过 180 个字符的英文表达。支持时可以先转写，再检查文字。iOS 使用本机识别，浏览器语音可能由浏览器供应商处理。主动发送时才将文字交给模型；只保留形成性反馈和参考说法，支持依建议再改写一次。判断不确定时回到参考说法。未以此改变 FSRS、判定发音或证明自由口语能力。
- **教学档案**。按近期多次作答决定补弱或推进。久别重返先复查。第 7 天或第 30 天后的复查窗口优先安排陌生材料。留出题不用于平时训练，使用过的材料不当作“陌生题”。周报列出样本数、学生实际选择过的行动和证据不足项。模型切换不会清空档案。
- **自愿的学习方式对照**。在「我的目标」开启，之后的同技能、同目标训练成对分配固定流程和错项分支；试验使用教研教材。按学习者、技能、目标、词汇位置区间、延迟和两分钟训练时长区间匹配复查成绩。可在同一页退出。只报告实际观察，不将空样本、模拟数据或前后差异解释成真实教学效果。该对照研究的是两种教学流程，不能独立证明整个产品优于所有背词工具。

## 验收边界

自动回归覆盖目标与档案隔离、旧课续学、新教材的生成/拒绝/冻结、两种诊断分支、撤销后旧提交失效、回应反馈、按天接续与计时。使用冻结时钟验证 7/30 日调度只说明程序能正确发放验证题。学习收益需要真实用户在相应日期返回。模型对开放回应的建议属于低风险练习；正式评分还需要教师标注的一致性评估。

更换模型或提示词后，在已配置混元的隔离测试环境运行 `python server/check_coach_model.py --live`。它会实际生成和审校三则新材料，再检查同义表达、合理澄清、地点说反和无关回答四个样例。使用合成材料，不读取学习者作答。这个检查会消耗套餐调用，只在显式传入 `--live` 时执行。

## 每日时间和学习档案

经典界面和教练课合并记录同一账号的练习用时。按约 30 分钟估算任务，30–40 分钟仅供参考，不再暂停、封顶或要求用户申请延长。首页、设置、完成小结及后台时间不计入。客户端先保存短时段记录，后台上传；网络慢、断网、另一台设备正在学习都不阻挡题目。相同时段重复上传不重复计时，两端重叠时段取并集。同账号按首次登记的时区划分学习日，跨午夜的时段分别归属。学习时间与每日不同词额度是两个独立指标。

客户端使用单调时钟记录前台练习的短时段并先保存在本地，上传失败自动重试。服务端在 SQLite 事务中按记录 ID 去重，并合并两台设备重叠的时间。离线练词无须事先预留时段。课程题目与作答依然需要联网，但不等待计时响应；已保存的背词任务可以离线继续。课内时间、教学目标、冻结的课程材料和作答证据存放在 personal.db 的独立 coach_* 表，包含在既有数据库备份中，旧版学习存档不会覆盖这些表。

## 两层回退

- **用户切换**。首页点「切回经典界面」，需要教练时再点「开启听读教练」。操作不删除课程、背词进度或今天的计时。iOS 和 Web 可各自保留界面偏好。
- **运维关闭试点**。在服务数据目录创建 `coach.disabled` 即停止发课和提交课程结果。用户回首页后隐藏教练入口，经典练习和共享时间继续工作。移走该标记即可重新开放。
- **代码发布故障**。完整回退基线为 Git 标签 `baseline-before-coach-20261104`（`8618ca3`）。切回发布前的前后端文件和兼容客户端，不卸载 App，不清本地存档，不用旧数据库覆盖上线后新增的学习。服务器发布备份中保存软件回退脚本及停写时制作的数据库备份。全量恢复旧二进制会恢复旧版自身的能力，包括旧版没有的计时功能。


## 2026-11-05：提前备课与非阻塞计时

- 完成课堂时，服务端将次日备课写入 `coach_jobs_v3`，无须手机继续运行。完成词汇一轮时 `/coach/finish` 更新薄弱词和位置，并预热下一批词的例句、单词音频。首页也会补交尚未准备的当日课程。
- 教材生成、审校和补充题解在内容工作线程处理；音频、词汇例句在另一工作线程处理。失败自动退避重试三次，持久化租期支持进程退出后的恢复。相同任务合并，已打开的课程不换教材。
- 次日材料带课程证据指纹。撤销或改变当天作答时重新备课；旧任务晚到的结果不能覆盖新依据。目标改变后旧目标的任务失效。课程资料不写 FSRS、掌握状态或学习名额。
- 教材审校通过后预生成原文和参考回应音频。课堂作答提交后预生成补充讲解，点击时先展示已缓存的讲解或课程题解。主动说写反馈仍须等用户提交实际内容。
- 薄弱词例句从完成页提前到练习中的后台任务，保留原任务 ID、版本和恢复机制。三句套装增加同词互斥，后台和前台同时请求不会重复生成。课堂音频输入上限与原文的 600 字符一致。
- 新客户端使用 `/coach/clock` 的 `record` 动作，上传有独立 ID 的短时段，保存在 `coach_time_v3`。旧客户端的 pulse 路径保留兼容，但服务端不再按 30/40 分钟拒绝开课或作答。身份验证、题目版本、重复作答与撤销保护仍保留。
- 验证：`server/test_coach_ready.py`、`server/test_coach_jobs.py`、既有 coach 三组回归；`tests/web_coach_e2e.cjs`、`tests/web_coach_time_recovery_e2e.cjs`；iOS `testCoachAdvisoryTimeInClassic` 与一屏导航。时间回归覆盖请求延迟、已练 60 分钟继续答题、进程重启补传、同 ID 重试、两端重叠和跨午夜。
- 回退只替换发布前的软件文件，不覆盖上线后的学习数据库。新增任务和时间表可保留，旧版本不会修改它们。已备教材仍沿用既有 `coach_prep_v2` 格式，新增 context 字段不影响旧字段读取。

## 2026-11-05：词义与例句同屏、答题操作下移

- iOS 新词页和复习答案页共用 `WordStudyPanel`：单词、音标、词义、当前中英例句直接同屏，取消词义／例句／跟读分栏。其他例句在底部“下一句”切换，播放、跟读、换句和纠错入口集中在底部。
- 自动朗读仅播放当前可见例句；尚未切换到的例句不计展示曝光。超长词义、例句和译文保留完整内容，从底部“更多”打开全文。跟读独立展开，录音与返回操作固定在下方。
- 复习、探测、新词验收、定级、独立校验共用底部四选一布局；反向题不提供单词播放，防止泄题。长选项保留全文确认流程，打开阅读不直接评分。
- 移动网页选择题同步下移，定级“不认识／退出”放在同一底部操作行；教练课堂保持原有布局。
- 验证：iPhone SE 模拟器检查四个选项、词义、例句和评分按钮无需滚动或分栏；长例句全文可逐字恢复，跟读能返回；换句失败保留原句、个性化句网络恢复可替换；新词验收、独立校验、猜测后的遗忘与重启继续学习、请求中的撤销与退出均通过。Web 在 320×568 和 390×844 检查按钮尺寸、底部位置、无页面滚动、评分和定级退出，并通过既有课堂与经典切换回归。
- 这是界面变更，无学习状态迁移。回退软件时保留用户新增进度；覆盖安装前仍需备份设备存档。
